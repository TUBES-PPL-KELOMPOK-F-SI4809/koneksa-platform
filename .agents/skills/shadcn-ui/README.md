# Skill komponen Koneksa

Entrypoint yang dipelihara untuk proyek Vue adalah [SKILL.md](SKILL.md).
Baca workflow tersebut sebelum memilih atau memasang komponen.

resources/, examples/*.tsx dan scripts/verify-setup.sh dipertahankan sebagai
referensi React upstream; bukan implementasi, installer atau validator untuk Vue.
Panduan proyek tidak mengharuskan React atau pemasangan toolkit UI baru.
