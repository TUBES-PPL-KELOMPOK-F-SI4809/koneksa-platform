# Pemetaan konteks

[AGENTS.md](../../AGENTS.md) adalah aturan operasional kanonis.
Gunakan bagian 2 untuk konteks/skill, bagian 4 untuk verifikasi, bagian 5 untuk handoff.
Cari aturan domain dengan rg sesuai kata kunci tugas; jangan memuat seluruh katalog.

| Kebutuhan | Baca bagian terkait |

| Struktur/arsitektur | [Pengembangan fitur](../../docs/guidelines/FEATURE-DEVELOPMENT-GUIDE.md), [Clean Code](../../docs/guidelines/CLEAN-CODE.md) |
| UI | [Baseline](../../docs/design-system/BASELINE-DESIGN.md), [Tokens](../../docs/design-system/DESIGN-TOKENS.md) |
| Test | [Testing](../../docs/guidelines/AGENT-UNIT-TESTING.md) |
