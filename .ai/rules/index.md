# Indeks aturan domain

Mulai dari [AGENTS.md](../../AGENTS.md). Path di tabel relatif terhadap root repo.
Baca hanya aturan yang cocok dengan berkas/dampak tugas; perubahan perilaku juga membaca testing.
Dokumen domain memperinci aturan utama, bukan menyimpan salinan aturan utama.

| Path atau dampak | Aturan |
|---|---|
| Semua tugas | [preflight.md](preflight.md) |
| app/**, routes/**, database/**, config/**, bootstrap/** | [backend.md](backend.md) |
| resources/**, konfigurasi frontend | [frontend.md](frontend.md) |
| tests/**, perilaku aplikasi, skema, konfigurasi test/CI | [testing.md](testing.md) |
| Dokumentasi/instruksi saja | AGENTS.md dan sumber dokumen terkait |
